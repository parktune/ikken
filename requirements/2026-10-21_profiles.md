# ikken 프로필 요구사항

작성 2026-10-21 · `/clarify:vague` 로 정리

## 원문

> ikken은 사용자마다(혹은 혼자서 디자인 프로필을 여러개 두어서) 프로필을 저장해서 그 사용자의 성향대로
> template이나 design 규칙, feedback이 남아야 해. 현재 repo를 그런 스타일에 더 맞도록 리팩토링하고 싶어.

## 목표

ikken 의 규칙·골격·피드백을 프로필 단위로 나눈다. 저장소가 배포하는 `default` 프로필은 배포자 스타일이고 계속 다듬어
배포한다. 각 사용자(또는 한 사람의 여러 벌) 프로필은 로컬에 두고 기본과 다른 점만 담는다.

## 구조

```
저장소
  SKILL.md · skills/feedback · skills/config      진행 절차 (프로필 해석 포함)
  scripts/profile.py · check.py · embed.py        엔진
  profiles/default/guide/*.md · templates/*.html · FEEDBACK.md

~/.claude/ikken/
  config.json                 {"active": "<이름>"}   ("default" = 저장소 기본)
  profiles/<이름>/
    profile.md                기본과 다른 규칙 (guide 이름별 절)
    tokens.css                (선택) 색·글꼴 토큰 — 골격 복사 때 기본 토큰 뒤에 붙음
    templates/<유형>.html     (선택) 골격 교체
    FEEDBACK.md               이 프로필의 피드백 이력
```

## 동작

- `/ikken` 처음 실행(config 없음): 프로필 이름 + 취향 질문 4개(화면 언어 · 색 분위기 · 설명 밀도 · 3D 회전 방향),
  모두 "기본 그대로" 가능. 기본과 다른 답만 기록. "default 그대로" 도 고를 수 있다.
- `/ikken`: default 규칙을 읽고 활성 프로필의 차이를 덮어쓴다(충돌하면 프로필이 이김).
- `/ikken:config`: 현재·목록 / `use` / `new [--from]` / `edit` / `delete`.
- `/ikken:feedback`: 활성 = default 이고 원본 저장소(쓰기 가능 git) → 저장소 기본에 반영 · commit · push.
  사용자 프로필 → 그 폴더만. 설치본에서 default 활성 → 내 프로필을 만들자고 안내.
  원저작자가 아닌 사람이 자기 clone 의 default 를 고치면 pull 충돌은 각자 관리.
- 기존 `~/.claude/ikken/preferences.md` 방식은 프로필로 대체.

## 결정 사항

| 질문 | 결정 |
|---|---|
| 저장 위치 | 저장소 = default, 사용자 프로필 = `~/.claude/ikken/profiles/` |
| 프로필 내용 | 기본과 다른 부분만 |
| 선택 | config.json 의 활성 프로필 하나, 처음 실행 때 설정 |
| 처음 설정 | 짧은 취향 질문 |
| 관리 호출 | `/ikken:config` |
| 피드백 대상 | 활성 = default 면 저장소(commit·push), 아니면 그 프로필 |
| 지금 규칙 | 그대로 default 로 계속 배포 (배포자 스타일 = 기본) |
| 자동 선택 | 필요 없음 (폴더별 · 한 번만 지정 없음) |

## 성공 기준

- 새 사용자가 처음 `/ikken` 에서 질문 몇 개로 프로필을 만들고, 이후 결과물에 그 차이(색 · 회전 방향 등)가 반영된다
- `/ikken:config use B` 뒤 다음 생성부터 B 스타일
- 활성 = default 일 때 피드백은 저장소에 commit · push, 다른 프로필일 때 저장소는 변하지 않는다
- 리팩토링 뒤에도 골격 점검(`check.py`)과 임베드 변환(`embed.py`)이 그대로 통과한다
