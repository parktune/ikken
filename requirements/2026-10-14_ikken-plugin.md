# ikken 플러그인 요구사항

작성 2026-10-14 · `/clarify:vague` 로 정리

## 원문

> 작업 폴더를 보면 여러 html 파일이 존재해. 이건 내가 어떤 알고리즘이나 데이터 등을 글 따위를 몇 시간씩 읽고
> 이해하는데 시간이 부족하니 가능한 빠르게 시각적 자료로 내 이해를 돕기 위해 만든거야. 앞으로도 이 프로세스
> 자체를 간단하게 수행할 수 있도록 클로드 plugin으로 만들고 싶어. 원하는 플러그인 이름은 "백문이불여일견"의
> "일견"을 일본식 발음으로 읽는 ikken이야. 앞으로 /ikken [Description] 등의 형태로 내가 이해하고 싶은 이론,
> 알고리즘, 데이터 등등이 있다면 html로 interactive 가능한 파일을 만들고 싶어. 플러그인은 github에 올릴 수
> 있도록 repo로 만들어.
>
> 사실 이렇게 plugin을 제작하지 않아도 이미 프롬프트만으로 artifact 생성이 가능하거나, eli5처럼 유사한
> 플러그인이 존재하기는 하지만, 이 작업을 하는 이유는 내가 원하는 설명 및 상호작용, 디자인 스타일이 있기
> 때문이야. 앞으로도 결과물을 보면서 항상 피드백을 줄게. 최종적으로 더할 나위 없이 좋은 품질이라고 생각하면
> 그 때는 더 이상 플러그인을 수정하지 않고 계속 사용하거나 다른 사내 직원들에게도 공유할 가능성이 있어.

추가 (같은 날): 외부 라이브러리는 기본적으로 CDN 을 허용하되, 사용자가 요청하면 Confluence 에 임베딩 가능한
버전도 만들 수 있게. Confluence 임베딩 유의 사항은 이전 임베드 경험을 참고.

## 목표

`/ikken <입력>` 한 번으로, 오래 읽어야 이해되는 이론·알고리즘·코드·논문·데이터를 몇 분 만에 "보고 만져서"
이해하게 하는 interactive HTML 한 장을 만든다. 설명·상호작용·디자인은 사용자 고유의 스타일을 따르고,
피드백이 쌓일수록 플러그인 자체가 좋아진다.

## 범위

포함

- 입력: 자연어 주제 · 로컬 코드/문서 경로 · URL/논문 PDF · 실제 데이터 파일 (섞어서도)
- `/ikken` — 재료 읽기 → 짧은 구성안 확인 → 단일 HTML 생성 → 점검 → 경로 보고
- `/ikken:feedback` — 피드백을 가이드(`guide/*.md`)·템플릿에 반영하고 commit, 필요하면 방금 만든 HTML 수정
- 스타일 가이드: 먼저 만든 HTML 과 이미 받은 시각화 피드백 규칙에서 추출
- Confluence 임베드 버전: 요청 시 `scripts/embed.py` 로 변환 (인라인 classic script, 2 MB 미만)
- `marketplace.json` — 나중에 `/plugin marketplace add` 로 사내 배포 가능

제외

- claude.ai Artifact 게시 (요청 시만)
- GitHub 원격 생성·push (나중에 지시)

## 결정 사항

| 질문 | 결정 |
|---|---|
| 입력 범위 | 자연어 · 로컬 코드/문서 · URL/PDF · 데이터 파일 전부 |
| 진행 방식 | 짧은 구성안 확인 후 생성 |
| 출력 | 로컬 단일 HTML (Artifact 는 요청 시) |
| 스타일 출발점 | 기존 HTML + 메모리 피드백 규칙 추출 |
| 화면 언어 | 한국어 기본, 용어는 영어 원문 |
| 피드백 반영 | `/ikken:feedback` → 가이드 수정 + commit |
| 라이브러리 | CDN 허용·버전 고정, classic(UMD) script 만. Confluence 버전은 요청 시 인라인 변환 |
| 배포 | 로컬 repo 만, push 는 나중에 |

## 성공 기준

- `/ikken "<주제>"`, `/ikken <경로>`, `/ikken <URL>` 모두 구성안 → 확인 → HTML 까지 이어진다
- 결과물이 먼저 만든 HTML 과 같은 계열(토큰 기반 라이트/다크, 패널, 고정 단계 컨트롤)로 보인다
- `/ikken:feedback "..."` 한 번이면 다음 생성부터 그 규칙이 적용된다
- Confluence 버전이 CSP 를 건 로컬 host 에서 빈 화면 없이 열린다
- 사용자가 "더 고칠 것 없다"고 할 때 동결하고 사내 공유
